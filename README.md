# Excel Formula Trainer for Data Analysts

An interactive web-based learning tool designed to help data analysts learn and practice essential Excel formulas.

This project provides explanations, examples, exercises, and quizzes to help users understand commonly used formulas in real data analysis workflows.

## 🌐 Live Demo
https://hanafidias.github.io/excel-formula-trainer

## 📚 Features

### 📗 Formula Learning
Explore **30+ essential Excel formulas** organized into 7 categories:

- 🔍 Lookup (VLOOKUP, XLOOKUP, INDEX MATCH, HLOOKUP, CHOOSE)
- ➕ Math & Statistics (SUMIFS, COUNTIFS, AVERAGEIFS, SUMPRODUCT, ROUND, LARGE)
- ✍️ Text (TEXTJOIN, LEFT/MID/RIGHT, TRIM, PROPER, TEXT, FIND, SUBSTITUTE)
- 📅 Date (TODAY, NOW, DATEDIF, EOMONTH, WORKDAY, YEAR/MONTH/DAY)
- ⚖️ Logic (IF, IFS, IFERROR, AND, OR)
- ℹ️ Info (ISBLANK, COUNT, COUNTA)
- ⚡ Dynamic Arrays (FILTER, UNIQUE, SORT)

Each formula includes:
- Syntax explanation
- Example formula
- Parameter explanation
- Sample data table
- Step-by-step usage guide

---

### ✏️ Practice Exercises
A set of **10 practice exercises** ranging from beginner to advanced level where users can type answers and check results instantly.

---

### 🎯 Quiz Mode
Test your knowledge with **10 multiple-choice questions**.

Features include:
- Category-based questions
- Instant answer explanation
- Final score summary

---

### 📋 Cheat Sheet
A quick-reference page summarizing all formulas in a single view for fast lookup.
